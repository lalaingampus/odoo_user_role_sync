The Manual Challenge

  • Time Consuming: Assigning 50+ individual security checkboxes per user for dozens of employees takes hours of manual clicking.
  • High Error Rate: Human error frequently leads to over-privileged or missing access rights across departments.
  • Difficult Auditing: Hard to share security matrices with HR, department leads, or external ISO auditors who work primarily with spreadsheets.
  • Reorganization Headaches: Bulk updates during department restructuring or mass onboarding cause significant administrative bottleneck.

The Smart Solution

  • Spreadsheet-Driven: Maintain user roles in standard Excel files and batch-sync directly into Odoo in seconds.
  • Interactive Preview: Verify matched accounts, target roles, and missing users before any database changes occur.
  • Selective User Sync: Toggle individual rows on/off to sync only the users you want without affecting others.
  • Standard OCA Architecture: 100% compliant with base_user_role, ensuring clean upgrade paths and zero vendor lock-in.

How the Smart User Matching Works

To ensure maximum flexibility when dealing with real-world spreadsheets from HR or IT departments, the wizard uses a 4-tier cascading matching engine:

Tier 1
Exact Login Match

Matches login case-insensitively (e.g. budi.santoso).

Tier 2
Exact Email Match

Matches email address (e.g. budi@company.com).

Tier 3
Name / Alias Match

Matches user's display name in Odoo contact card.

Tier 4
Email Prefix Match

Extracts username prefix prior to @ if full email differs from login.

Safety First: If a row in Excel does not match any user in Odoo, it is flagged as Belum Ada di Odoo and automatically unchecked. It will not cause errors, crashes, or unintended user record creations.
